# Embedded icon set: provenance

- **Files:** `include/xxwidgets/xxwidgets_icons.h` and `src/xxwidgets_icons_data.c`
  are generated by `tools/gen_icons.py`; do not edit them by hand.
- **Source:** every `<Name>.16.16.png` in `_mylibs/XStyles/icons`
  (XStyles, Copyright (c) 2020-2026 hors <horsicq@gmail.com>, MIT License,
  the same author and licence as xxwidgets).
- **Conversion:** decoded by the script's own PNG reader (no third-party code)
  to straight-alpha RGBA8 at 16 x 16:
  - `Open.16.16.png` is a 24 x 24 palette PNG with a tRNS chunk; it is
    converted to RGBA and area-averaged (premultiplied alpha) to 16 x 16;
  - `Virustotal.16.16.png` is 16 x 15; it is centred on a transparent
    16 x 16 canvas;
  - all other icons are copied pixel for pixel (checked against Pillow).
- **Stable ids:** `xxwidgets_icon_id` is public API. The script keeps the order
  of the existing header and appends new icons; a removed icon keeps its id
  with no pixels.
- **Regenerate / check:** `python tools/gen_icons.py` and
  `python tools/gen_icons.py --check`.
